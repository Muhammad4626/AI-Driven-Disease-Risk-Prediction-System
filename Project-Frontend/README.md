# AI-Powered Disease Risk Predictor for Pakistan - Frontend

A React.js frontend application for predicting disease risks using AI technology, specifically designed for the Pakistani population.

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

The application will open at `http://localhost:3000`
